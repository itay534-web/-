# כל השונה הלכות – תשפ"ז (אפליקציה מקומית, ללא אינטרנט)

## מה יש בתיקייה
| קובץ | תפקיד |
|---|---|
| `www/data.js` | **קובץ הנתונים** – כל 385 ימי תשפ"ז, מילה במילה לפי ה-PDF |
| `www/index.html`, `www/style.css`, `www/app.js` | **קוד האפליקציה** (ממשק, לוח עברי, חיפוש, תזכורת, לוח "קראתי") |
| `package.json`, `capacitor.config.json`, `scripts/` | עטיפת אנדרואיד (Capacitor) שמאפשרת התראות אמיתיות גם כשהאפליקציה סגורה |
| `.github/workflows/build-apk.yml` | בניית APK אוטומטית בענן (דרך א') |

## בדיקה מהירה – בלי שום התקנה
פתחו את `www/index.html` בדפדפן (כרום) במחשב או בטלפון. האפליקציה עובדת מקומית לגמרי.
(בדפדפן התזכורת תקפוץ רק כשהדף פתוח – התראה אמיתית ברקע דורשת התקנה כ-APK.)

## דרך א' – בניית APK בענן (בלי להתקין כלום במחשב)
1. פתחו חשבון חינמי ב-https://github.com ← **New repository** ← שם כלשהו ← Create.
2. בעמוד הריפו לחצו **uploading an existing file** וגררו פנימה את **כל התוכן** של התיקייה (כולל התיקייה `.github` – אם היא מוסתרת, הפעילו "הצג קבצים מוסתרים"). לחצו **Commit changes**.
3. עברו ללשונית **Actions** ← **Build APK** ← **Run workflow**. המתינו כ-5–8 דקות עד שמופיע וי ירוק.
4. היכנסו לריצה שהסתיימה ← למטה ב-**Artifacts** הורידו `kol-hashoneh-apk` (קובץ ZIP ובתוכו `app-debug.apk`).

## דרך ב' – Android Studio (במחשב)
1. התקינו **Node.js (גרסת LTS)** מ-https://nodejs.org ואת **Android Studio** מ-https://developer.android.com/studio (עם אשף ההתקנה הרגיל).
2. פתחו טרמינל (Windows: PowerShell) בתוך תיקיית הפרויקט והריצו:
   ```
   npm install
   npm run setup
   npm run open
   ```
3. ב-Android Studio המתינו לסיום ה-Gradle Sync, ואז: **Build ← Build Bundle(s)/APK(s) ← Build APK(s)**. בסיום לחצו **locate** כדי לראות את `app-debug.apk`.
   (או חברו טלפון עם "ניפוי באגים ב-USB" ולחצו ▶ Run.)

## התקנה בטלפון
1. העבירו את `app-debug.apk` לטלפון (וואטסאפ לעצמכם / USB / דרייב).
2. פתחו אותו בטלפון ואשרו "התקנה ממקורות לא ידועים" כשהמכשיר מבקש.
3. בפתיחה ראשונה, בחלונית התזכורת (🔔) סמנו "הפעל תזכורת יומית", בחרו שעה ואשרו הרשאת התראות.
   אם התראה לא קופצת: הגדרות ← אפליקציות ← כל השונה הלכות ← התראות (להפעיל), וגם ← סוללה ← "ללא הגבלה" (בחלק מהמכשירים, כמו שיאומי/סמסונג, יש חיסכון אגרסיבי בסוללה).

## התאמות
- **להוסיף/לתקן הלכות:** לערוך את `www/data.js`. לכל יום: `h` תאריך, `s` נושא, `d` שורות הקדשה, `b` ההלכות (`t` כותרת, `b` גוף, `s` מקור).
- **אחרי כל שינוי בקבצי `www`:** `npm run sync` (או להעלות מחדש ל-GitHub ולבנות שוב).
- **שנה חדשה:** להחליף את `data.js` ולעדכן את `start` (תאריך לועזי של א' תשרי) ואת מספר ימי החודשים ב-`HEB_MONTHS` בראש `app.js` (בשנה פשוטה אין אדר א'/ב' אלא אדר אחד).
